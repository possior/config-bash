# 技術文書

`.bash_profile`ファイルの設定は、ログイン時に１度だけ読み込まれる。

## 目次

- [設定を参照する](#設定を参照する)

## 設定を参照する

ホームディレクトリに`.bashrc`ファイルが存在すれば、その設定を参照する。

```bash
if
  [[ -f ${HOME}/.bashrc ]]
then
  source ${HOME}/.bashrc
fi
```

# Technical Document

Configuration in the `.bash_profile` file loads once when you log in.

## Reference Configuration

If a `.bashrc` file exists at the home directory, reference its configuration.

```bash
if
  [[ -f ${HOME}/.bashrc ]]
then
  source ${HOME}/.bashrc
fi
```
