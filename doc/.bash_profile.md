# Bash説明書

以下のBashスクリプトは、`$HOME/.bashrc`設定ファイルが存在することを確認した後に、それをセッションに読み込む。

```Bash
if [[ -f "$HOME/.bashrc" ]]
then
  source "$HOME/.bashrc"
fi
```

# Bash Document

The Bash script below loads the configuration file `$HOME/.bashrc` into the session after checking if it exists.

```Bash
if [[ -f "$HOME/.bashrc" ]]
then
  source "$HOME/.bashrc"
fi
```
