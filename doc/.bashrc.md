`.bashrc`ファイルの設定は、セッション毎に１度だけ読み込まれる。

## 目次

## 設定ディレクトリを参照する

設定ディレクトリ（`${HOME}/.config/bash`）に`bash.sh`ファイルが存在すれば、その設定を参照する。

``` bash
if
  [[ -f ${HOME}/.config/bash/bash.sh ]]
then
  source ${HOME}/.config/bash/bash.sh
fi
```

## Reference Configuration Directory

If a `bash.sh` file exists at the configuration directory (`${HOME}/.config/bash`), reference its configuraiton.

``` bash
if
  [[ -f ${HOME}/.config/bash/bash.sh ]]
then
  source ${HOME}/.config/bash/bash.sh
fi
```
