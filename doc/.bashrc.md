# 技術文書

`.bashrc`ファイルの設定は、セッション毎に１度だけ読み込まれる。

``` bash
if
  [[ -f ${HOME}/.config/bash/bash.sh ]]
then
  source ${HOME}/.config/bash/bash.sh
fi
```

# Technical Document

Configuration in the `.bashrc` file loads once for each session.

``` bash
if
  [[ -f ${HOME}/.config/bash/bash.sh ]]
then
  source ${HOME}/.config/bash/bash.sh
fi
```
