# Bash説明書

以下のBashスクリプトは、`$HOME/.config/bash/bash.sh`設定ファイルが存在することを確認した後に、それをセッションに読み込む。

```Bash
if [[ -f "$HOME/.config/bash/bash.sh" ]]
then
  source "$HOME/.config/bash/bash.sh"
fi
```

# Bash Document

The Bash script below loads the configuration file `$HOME/.config/bash/bash.sh` into the session after checking if it exists.

```Bash
if [[ -f "$HOME/.config/bash/bash.sh" ]]
then
  source "$HOME/.config/bash/bash.sh"
fi
```
